**Iris Flower Classification**

* Performed EDA on the Iris dataset: missing value imputation (mean/median), duplicate detection, outlier analysis via boxplots, scater plot matrices, and correlation heatmaps.
* Split data 80/20 with stratification and fixed random seed
* Built KNN using scikit-learn, comparing Euclidean vs. Manhattan distance metrics
* Tuned k via 5-fold cross-validation; visualized accuracy vs. k
* Implemented Gaussian Naive Bayes and evaluated both models on test accuracy, with misclassification analysis
